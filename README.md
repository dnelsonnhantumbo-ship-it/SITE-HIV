# Site: Prevenção do HIV-SIDA

Site estático (HTML + CSS) com as secções do projecto: Definição, Objectivos, Planeamento e produção.

## Publicar no Render (grátis)

1. Crie uma conta em https://github.com e um repositório novo (ex.: `hiv-sida-site`).
2. Envie para lá os ficheiros `index.html`, `style.css` e `render.yaml`
   (no GitHub: *Add file > Upload files*, arraste os 3 ficheiros e faça *Commit*).
3. Crie uma conta em https://render.com e entre com o GitHub.
4. Clique em **New +** > **Static Site** e escolha o repositório.
5. Preencha:
   - **Build Command:** deixe vazio (ou escreva `echo ok`)
   - **Publish Directory:** `.`
6. Clique em **Create Static Site**. Em 1 a 2 minutos o site fica online num endereço `https://hiv-sida-site.onrender.com`.

Alternativa: **New +** > **Blueprint** e escolha o repositório; o Render lê o `render.yaml` sozinho.

## Alterar o conteúdo

Edite o `index.html` no GitHub e faça *Commit*. O Render publica a nova versão automaticamente.
